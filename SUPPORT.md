# Support

Reasoning is community-supported, pre-1.0 software. There is no guaranteed
response time or managed operations service.

For usage questions, reproducible bugs, and feature requests, use this
repository's GitHub issues after searching existing reports. Security problems
must follow [SECURITY.md](SECURITY.md).

When requesting help, include:

- the exact Git revision or release ID;
- operating system and CPU architecture;
- the command or documented workflow being followed;
- the last non-secret error and current phase; and
- whether the operation may have created billable or externally visible state.

For a wizard-managed deployment, keep the original state directory and run the
same command again unless the guide says otherwise. Do not post tokens,
passwords, private keys, setup credentials, provider authorization codes,
cookies, full private state files, or unredacted database contents.

Useful starting points are the [documentation index](docs/README.md),
[deployment guide](docs/deployment.md), and
[operations guide](docs/operations.md).
